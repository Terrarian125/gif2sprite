# スプライトシート・ツールボックス Pro 🚀

複数の画像からスプライトシート（組み画像）を作成したり、逆にスプライトシートを個別の画像に分解したりできる、ゲーム制作やドット絵編集に便利なデスクトップツールです。アニメーションGIFとの相互変換にも対応（一部開発中）しています。

CustomTkinterを採用した、モダンなダークモード仕様のGUIアプリケーションです。

---

## 🔥 主な機能

| 機能 | 概要 | ステータス |
| :--- | :--- | :--- |
| 🖼️ **画像 ➔ シート** | 複数の連続した画像を選択し、指定した格子（縦×横）のスプライトシートに結合します。 | **実装済み** |
| ✂️ **シート ➔ 画像** | 1枚のスプライトシートを、指定した格子数で自動分割して連番画像として保存します。 | **実装済み** |
| 🎨 **シート ➔ GIF** | スプライトシートをアニメーションGIFに変換します。 | *近日公開 (Coming Soon)* |
| 🎞️ **GIF ➔ シート** | アニメーションGIFの各フレームを検出し、1枚のスプライトシートに自動で並べ替えて結合します。 | **実装済み** |
